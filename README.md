# 💰 תזרים מזומנים

אתר לניהול תזרים מזומנים אישי, בעברית. כל אחד נכנס עם חשבון משלו (Google או אימייל וסיסמה), ורואה רק את הנתונים של עצמו. הנתונים נשמרים בענן, כך שאפשר להתחבר מכל מחשב או טלפון.

**מה יש באתר:**
- קטגוריות של הכנסות ושל הוצאות, עם תקציב חודשי לכל קטגוריית הוצאה
- הזנת תנועות (תיאור וסכום) ישר מתוך כרטיס הקטגוריה. כל תנועה נשמרת עם תאריך ושעה
- יתרת פתיחה, יתרת סגירה ויתרה מצטברת בכל שורה
- תרשים של 12 חודשים: הכנסות, הוצאות ויתרה צפויה
- פילוח הוצאות לפי קטגוריה
- ייצוא ל-CSV שנפתח ב-Excel
- מותאם לטלפון ולמצב כהה

כל עוד Firebase לא הוגדר, האתר עובד **במצב הדגמה**: הנתונים נשמרים רק בדפדפן ואין חשבונות אמיתיים.

---

## שלב 1: יצירת פרויקט Firebase (חינם, כ-10 דקות)

1. נכנסים ל-https://console.firebase.google.com ולוחצים **Add project**. בוחרים שם, ואפשר לכבות את Google Analytics.
2. **Authentication** → **Get started** → בלשונית **Sign-in method** מפעילים:
   - **Email/Password**
   - **Google** (בוחרים אימייל תמיכה ושומרים)
3. **Firestore Database** → **Create database** → בוחרים מיקום (למשל `europe-west1`) → **Start in production mode**.
4. בלשונית **Rules** של Firestore מוחקים את מה שיש, מדביקים את התוכן של הקובץ `firestore.rules` ולוחצים **Publish**.
   *זה השלב שמבטיח שאף משתמש לא יוכל לראות נתונים של משתמש אחר, אז אסור לדלג עליו.*
5. ⚙️ **Project settings** → למטה ב-**Your apps** לוחצים על סמל `</>` (Web) → נותנים שם → **Register app**.
   מעתיקים את האובייקט `firebaseConfig` ומדביקים אותו במקום הקיים בקובץ **`firebase-config.js`**.

> המפתח `apiKey` של Firebase **אינו סוד**, ומותר שיופיע באתר ציבורי. מה שמגן על הנתונים הם כללי האבטחה משלב 4.

## שלב 2: העלאת האתר לאינטרנט

### אפשרות א': GitHub Pages (הכי פשוט, כי הקוד כבר ב-GitHub)
1. ב-GitHub נכנסים לריפו → **Settings** → **Pages**.
2. תחת **Source** בוחרים **Deploy from a branch**, ואז את הענף (`main`) ואת התיקייה `/ (root)` → **Save**.
3. אחרי דקה-שתיים האתר זמין בכתובת `https://<שם-המשתמש>.github.io/cashflow/`.

### אפשרות ב': Firebase Hosting
```bash
npm install -g firebase-tools
firebase login
firebase use --add        # בוחרים את הפרויקט
firebase deploy           # מעלה גם את האתר וגם את כללי האבטחה
```
האתר יהיה בכתובת `https://<project-id>.web.app`.

## שלב 3: אישור הדומיין להתחברות
ב-Firebase: **Authentication** → **Settings** → **Authorized domains** → **Add domain**,
ומוסיפים את הדומיין של האתר, למשל `<שם-המשתמש>.github.io`. (`web.app` ו-`localhost` כבר מאושרים כברירת מחדל.)

זהו. עכשיו אפשר לשלוח את הקישור לכל מי שרוצים: כל אחד נרשם ומקבל תזרים פרטי משלו.

## הרצה מקומית
האתר סטטי, אז מספיק שרת קבצים פשוט:
```bash
python3 -m http.server 8000
# ואז פותחים http://localhost:8000
```

## מבנה הקבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה הדף |
| `style.css` | עיצוב (RTL, מותאם לטלפון ולמצב כהה) |
| `app.js` | הלוגיקה: התחברות, שמירה, חישובים ותרשים |
| `firebase-config.js` | ההגדרות של פרויקט ה-Firebase שלכם |
| `firestore.rules` | כללי אבטחה: כל משתמש ניגש רק לנתונים שלו |
| `firebase.json` | הגדרות ל-Firebase Hosting |

הנתונים נשמרים ב-Firestore תחת `users/{uid}/transactions`.
